# ContPlus Web - Frontend

Modern web interface for the ContPlus 6 replacement accounting system.

## Stack
- Next.js (App Router)
- TypeScript
- Supabase (Auth + Data)
- Tailwind CSS / shadcn/ui
- Vercel (Hosting)

## Setup
```bash
npm install
cp .env.example .env.local
# Fill in Supabase project variables
npm run dev
```

## Features
- Multi-company accounting
- Chart of accounts management
- Journal entries / Daily book
- General ledger
- Balance sheet & Income statement
- IVA/VAT management (El Salvador)
- Check management
- Financial reports
